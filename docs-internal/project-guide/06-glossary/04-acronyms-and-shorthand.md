# Acronyms And Shorthand

> **Purpose:** Expand technical shorthand used in code and documentation.
> **Read this before:** Reading implementation notes or debugging logs.
> **Source files:** `CLAUDE.md`, `ARCHITECTURE.md`, `requirements/base.txt`

- **API** — Application Programming Interface.
- **BALD** — Bayesian Active Learning by Disagreement; used for candidate acquisition.
- **CSRF** — Cross-Site Request Forgery protection supplied by Django middleware.
- **EEA** — European Economic Area; relevant to contact contribution geo-gating.
- **FSM** — finite-state machine, notably the Deal and account connection lifecycles.
- **GP / GPR** — Gaussian Process / Gaussian Process Regressor used in ranking and confidence gating.
- **HTMX** — HTML-driven request/swap library used for navigation and polling.
- **LLM** — large language model used for qualification, summaries, and message generation.
- **M2M** — many-to-many database relationship.
- **PID** — operating-system process identifier stored by `BotProcess`.
- **SMTP** — protocol used to send outbound email.
- **URN** — LinkedIn entity identifier used for profiles and message deduplication.
- **Voyager** — LinkedIn's internal web API consumed through the external `linkedin_cli` package.
